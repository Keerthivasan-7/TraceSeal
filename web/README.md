# web

Not yet implemented. The React UI is built incrementally alongside the
services it drives — Officer Inbox/Viewer from **Milestone M3**, Investigate
flow from **Milestone M5** — and polished into the full Command Center in
**Milestone M8**.

React 18 + TypeScript strict + Vite + Tailwind + shadcn/ui + TanStack Query +
Zustand + Recharts, all assets vendored locally (no CDNs, no runtime egress).

See `docs/SPEC.md` Section 5 and Section 14.
